# theater-stage

A 3D theater stage for AI actors, built with Three.js.

## What's here

The application is under `projects/scratch/`, which has its own README with the full feature list. From that README:

- A 20x15 unit stage with nine blocking markers (USL through DSR).
- Curtains, four elevating platforms, a rotating center stage, trap doors, and sliding scenery panels.
- A lighting system with presets (Default, Day, Night, and others).
- Save/load of stage state, undo/redo, and collision detection.

`projects/scratch/__tests__/` holds a Jest suite covering geometry, lighting, physics, props and actors. `docs/` holds API documentation, a user guide, a curriculum guide, and a modularization plan.

## Note

The code lives at `projects/scratch/`, not at the repository root. Start there.
